# 島嶼市長：產品需求文件（PRD）

版本：0.1｜狀態：規劃草案｜日期：2026-10-28

## 1. 產品目標

以 [Island Mayor 故事書風格](https://island-mayor.tyctc128.workers.dev/?style=storybook)為參考，製作具有同等頁面結構、操作流程與遊戲體驗的繁體中文網頁應用，並提升視覺細節、動態回饋、適應不同螢幕的能力及語音品質。使用者可直接進入體驗，不需要登入，也不使用資料庫。

目前環境存取參考網址時，網路代理回傳 403。參考站的實際畫面、流程、規則與音訊尚未完成盤點；本文中具體畫面與流程均是待驗證的規劃，不代表已確認原站功能。取得存取後，須先更新本文件及 SDD，再以盤點結果為實作依據。

## 2. 使用者與體驗原則

使用者希望透過直覺的故事與選擇體驗島嶼治理。介面應以繁體中文、易讀文字、明確操作和溫暖的故事書氛圍呈現，讓首次使用者無須閱讀技術說明即可開始。視覺與聲音應服務資訊理解，避免動畫或音效遮擋操作。

本階段不包含多人同步、跨裝置存檔、後端服務或登入。具體遊戲內容、數值、頁面數及是否重現所有支線，以參考站盤點結果確定。進度存在使用者裝置上，清除瀏覽器資料可能使進度消失。

## 4. 體驗流程與狀態

待盤點確認的代表性流程：進入首頁 → 開始／繼續 → 主遊戲畫面 → 事件或對話 → 選擇 → 結果與狀態更新。須同時盤點返回、關閉、重置、音訊啟用、載入失敗及資料不存在等分支，不能只實作靜態畫面。

## 5. 美術與聲音品質

視覺以參考站的布局與氛圍為基準，統一字級、色彩、插圖比例、紙張質感、陰影、動態節奏及元件狀態。改善文字對比、資訊層級、觸控範圍及小螢幕排版。素材使用前確認權利；不可使用時製作可合法使用的原創素材，並記錄與參考的差異。

語音優先使用具商用授權的真人配音或高品質預製合成語音，每位角色建立一致聲線、語速及情緒規範；避免以瀏覽器即時朗讀作為最終品質。規劃台詞表、音訊授權、字幕、發音校對與人工聆聽審核。聲音分軌控制，音量一致並避免削波；目標語音約 -16 LUFS、true peak 不高於 -1 dBTP，實際依素材與混音檢查調整。沒有可用的授權語音供應方式時，標為未完成，不能以靜音冒充完成。

## 6. 交付與驗收

1. 參考站盤點及差異清單，確認內容與素材權利。
2. 設計系統與一段包含畫面、互動、狀態及語音的可玩垂直切片。
3. 完整主要流程、對應狀態與音訊。
4. 依畫面清單進行視覺、功能、響應式、無障礙與音訊驗收，記錄通過、失敗及未測項目。

品質指標：主要操作區建議至少 44 × 44 CSS px；文字對比以 WCAG 2.2 AA 為目標；核心流程不應有水平溢出或遮擋。效能以實際裝置測量為準，目標行動網路下 LCP ≤ 2.5 秒、CLS ≤ 0.1；需記錄測試條件，未達標時列出原因與改善。

## 7. 待確認事項與風險

- 開放參考網域或提供完整操作錄影與桌機／手機截圖，才能確定實際功能及還原範圍。
- 確認原站視覺、文字、音樂與語音素材是否可使用，及商用授權範圍。
- 決定配音來源、角色聲線、預算與語音製作方式；缺少素材會影響音訊交付。
- 本機存檔不支援跨裝置同步，也可能受瀏覽器儲存政策影響。
